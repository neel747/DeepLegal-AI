# DeepLegal AI

DeepLegal AI is a multi-agent contract intelligence system featuring GraphRAG, hybrid retrieval, and self-correcting reasoning.

## 🚀 Overview
Building a production-grade AI system to parse, analyze, and query legal contracts with high precision.

## 🛠 Features
- **Legal-Aware Ingestion**: Advanced parsing and chunking of PDF/DOCX files.
- **Knowledge Graph (Neo4j)**: Visualizing and querying relationships between contracts and clauses.
- **Hybrid Retrieval**: Combining Dense (FAISS) and Sparse (BM25) search for maximum accuracy.
- **Multi-Agent Orchestration**: Powered by LangGraph for reasoning and self-correction.
- **Production Ready**: FastAPI backend and React frontend.

## 📂 Project Structure
- `src/`: Core logic (ingestion, retrieval, agents).
- `data/`: Sample legal documents (ignored by git).
- `tests/`: Unit and integration tests.
- `PLAN.md`: Detailed implementation roadmap.
- `CHANGELOG.md`: Tracking project progress.
